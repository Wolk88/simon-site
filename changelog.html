What's New

SiMon - System Monitor

Every release of SiMon, newest first, described in plain terms. The version you are running is shown at the bottom of Settings, under General.

Older entries describe every feature SiMon has had. Which of them your copy includes depends on where it came from; Settings always shows what is actually available.

Version 1.8.0

26 November 2026

This release is for the download from this site. Power, the list of apps, the speed measurements and everything about fans need access the App Store does not allow.

Power

The panel has a Power row: how many watts the whole Mac is drawing, with a graph, the share of the graphics processor, and the average, the peak and the watt-hours over the time the graph covers. It can also be shown in the menu bar; that is off by default and is switched on in Settings, Power. I could not check whether the reading includes battery charging, so treat the number with care while the battery is charging.

Network and disk

Download and upload speed and disk read and write speed, in the panel and optionally in the menu bar. Both are off by default; see Settings, Net & disk. Only Wi-Fi, Ethernet and a tethered phone are counted, so traffic through a VPN is not counted twice.

The same section has two buttons. "Measure connection speed" runs the test that comes with macOS. "Measure disk speed" writes a 2 GB file to the startup disk, reads it back and deletes it; it refuses to start when free space is short.

The heaviest apps

At the bottom of the panel there is a list of the five apps using the most processor time or memory. Helper processes are counted with their app. System services are not listed: macOS does not let an app read them without administrator rights. The list is read only while the panel is open and can be switched off in Settings, General.

Alerts

SiMon can send a notification when the chip stays above 90° for five minutes, when swap grows by 2 GB within ten minutes, or when macOS reports memory pressure. Each alert comes once per episode and not more often than once in half an hour. The thresholds, each alert separately and all of them together are in Settings, Alerts. macOS asks for permission to show notifications the first time this version starts.

Detailed log

SiMon now writes one CSV file per day, a line every ten seconds: average and peak load, memory, power, the highest temperature and fan speed. The files are kept for 7, 30 or 90 days, take about a megabyte a day and never leave the Mac. The log is on by default; the switch and the folder are in Settings, General, Log.

Fans

Two new conditions for rules: a process with a given name is running, which also covers command-line tools and not only apps, and the load on the graphics processor has stayed above a given percentage.

"Speed up ahead of heat" is an experiment and is off by default. When the Mac draws more than the chosen number of watts for a few seconds, the fans are raised a little before the temperature follows. On my M5 Pro the effect is modest. It does not act while the battery is charging.

Fixed

Every change of the refresh interval in Settings started one more daily check for a new version on GitHub.

Version 1.7.1

17 November 2026

Fan control survives sleep

In 1.6.0 and 1.7.0 the fan mode quietly went back to Automatic after the Mac slept: the helper handed the fans to macOS when the app stopped responding, which is correct, but the app then took that as a reason to switch the mode off for good. Now the mode you chose is switched back on after wake. If you set a constant speed or a curve in one of those versions and found Automatic selected later, this was the cause; choose your mode again once.

The power adapter rule and the rule for a running app have now been tried on a real machine as well.

Version 1.7.0

16 November 2026

Like 1.6.0, this release is for the download from this site only.

Presets

Settings, Fans has a Presets block. A preset keeps the mode, the speeds or the curve, and what the fans do when the Mac is cool. Automatic, Quiet, Balanced and Cool are built in; "Save current settings" adds your own.

Rules that switch presets for you

A rule is a condition and a preset: on battery, on power adapter, Low Power Mode is on, or a particular app is running. The first rule in the list whose condition holds decides the preset. While a rule is in effect your own settings are set aside and locked in the window; they come back when the rule no longer applies, also after a restart of SiMon. Only the battery rule has been tried on a real machine so far.

Fan control from the terminal

The running app takes commands through its own binary, /Applications/SiMon.app/Contents/MacOS/SiMon:

--fan status shows the fans, the temperature, the mode and the rule in effect; --fan presets lists presets; --fan preset <name> applies one; --fan auto hands the fans back to macOS; --fan speed <rpm> holds a constant speed; --fan rules on|off switches the rules. The speed is kept within each fan's range, and the exit code is 0 on success.

Fixed

After switching from By temperature to Constant, the status line kept the last message from the curve.

Version 1.6.0

16 November 2026

This release is for the download from this site. The Mac App Store edition has no access to the fans, so nothing here applies to it.

SiMon can drive the fans

Settings, Fans has a new block. After you install a small system helper (macOS asks for permission once), three modes are available: Automatic leaves the fans to macOS, Constant holds the speed you set, By temperature follows a curve.

Curves and profiles

Quiet, Balanced and Cool are ready-made curves; Custom is yours. Points on the graph can be dragged, and a double-click adds one. Two sliders set how fast the fans speed up and slow down, and the hysteresis keeps them from hunting around a point. The curve follows the hottest core, read once a second.

Fans can stop when the Mac is cool

Below the curve the fans can go back to macOS, idle at their minimum, or stop below a temperature you choose between 35 and 55 degrees. A stopped fan needs a few seconds to spin up, so a sudden heavy load heats the chip more than with idling fans.

Try a curve before you trust it

Two buttons under the graph run a minute of full load: one with your curve, one with macOS in charge. Both runs are drawn on the same chart with the peak temperature, how soon the fans reached half speed and how much the processor slowed down. On the MacBook Pro with M5 Pro this was written on, the Balanced profile lost about 1% of processor speed over the minute and macOS about 9%.

What keeps it safe

The helper does not trust the app. If SiMon quits or hangs, the fans go back to macOS within seconds. If the hottest core reaches the safety limit (95 degrees, and you can lower it), the helper runs the fans at full speed until the chip cools down, and ignores everything else meanwhile. It refuses to stop a fan on a chip warmer than 60 degrees. Before the first use on a Mac it runs a short check that raises the fan speed a little and confirms the firmware obeys; if it does not, SiMon stays in Automatic and says why.

Fan control was tested on one machine, a MacBook Pro with M5 Pro. Other chips are covered by the check above and by a workaround for M4 that has not been run on a real M4 yet.

Updates install from the panel

The line about a new version now has an Update button. SiMon downloads the disk image from the releases page, installs it only if it is signed by the developer and notarised by Apple, and restarts. A switch in Settings, General does this without asking; it is off by default.

Version 1.5.0

7 November 2026

The menu bar block has five looks now

The old layout spent about 320 points of the menu bar on an icon, a number and a mini graph for every metric. Four more compact arrangements are available in Settings under General: two rows with text labels, two rows with icons, rings, and rings with values. The narrowest of them fits the same metrics into 118 points.

One temperature instead of three

The menu bar used to carry three pairs like C68 D41 B32. It now shows a single reading: the hottest of the sensors you enabled, with a letter for the node it came from, coloured green below 65 degrees, yellow up to 85 and red above that. The panel still lists every sensor. Temperature settings moved into their own section, and the colouring by heat level can be switched off there.

Fans report the fastest one

The figure used to be an average across both fans, which produced a number that did not exist in the machine: halfway between a spinning fan and a stopped one. It now shows the fastest fan.

Three colours per metric

The indicator, the icon and the value can each take their own colour, instead of one setting for the graph. Colours set in earlier versions carry over to the indicator.

It tells you when a new version is out

SiMon checks the releases page once a day and on launch. When something newer is there, a line appears at the bottom of the panel with a link to it. Nothing is sent anywhere, and network errors stay silent.

Version 1.4.0

27 August 2026

Core groups are named by the chip, not by habit

The rows of per-core bars used to be labelled E and P, which was true for the M1 through M4 and wrong everywhere else. An M5 Pro has no efficiency cores at all: its levels are Performance and Super, so twelve performance cores were sitting under the letter E. SiMon now asks the system what its core levels are called and labels them accordingly.

More than two kinds of core

The M6 has three core levels rather than two, and the panel draws a group for each one instead of assuming there are exactly two. Machines with a single level are drawn as one group.

Version 1.3.1

14 August 2026

Housekeeping

Maintenance release. The application category is now declared explicitly, the copyright line was corrected, and the build no longer carries a quarantine flag from files used during packaging. Metrics, the panel, the history and the settings are unchanged.

Version 1.3.0

13 August 2026

The stress test moved into Settings

Checking that a Mac holds up under load is now a section of the Settings window, next to the metrics, instead of a separate window. The run keeps going if you close Settings, and reopening the section shows where it got to.

A word about safety

The stress test deliberately heats the machine, so it now says so plainly before it starts. macOS manages temperature itself and SiMon stops the run if a sensor passes 100 degrees, but you start it yourself and run it at your own risk.

Version 1.2.0

13 August 2026

History now survives a restart

Metrics are kept for a fixed stretch of time rather than a fixed number of samples, so the panel always shows the last ten minutes no matter how often SiMon polls. A day of history is also written to disk, which makes slow problems like a memory leak visible across restarts.

Only one copy runs at a time

Launching SiMon while it is already running now brings the existing copy forward instead of adding a second set of readings to the menu bar.

Honest scale for the Neural Engine graph

The graph used to be drawn against a fixed 8 W ceiling borrowed from the M1. It is now scaled to the highest power draw actually seen, and the caption tells you what that peak is. On this machine the real peak under a machine learning workload is closer to 2.8 W, so activity that used to look flat is now clearly visible.

Signing fixed

The notarisation ticket is now attached to the application itself, not only to the disk image, so macOS can verify SiMon without an internet connection.

This page

Release notes now have a home, and Settings has a "What's new" link that brings you here.

Apple Silicon only

SiMon requires a Mac with Apple Silicon. Intel Macs were never really supported - the Neural Engine, the temperature sensors and the split between efficiency and performance cores do not exist there - and the requirement is now stated plainly.

Version 1.1.0

13 August 2026

Processor load split into apps and system

The CPU reading now separates the work your own apps are doing from the work macOS is doing on their behalf. When the machine feels busy for no obvious reason, this shows at a glance whether an app or the system is behind it. The per-core bars also adapt their thickness to how many cores your Mac has, so they stay readable from an 8-core chip up to a 64-core one.

Memory and battery temperatures

Two more sensors joined the temperature readings, and you can now pick which of them appear in the menu bar. Sensor names differ between Apple chips, so SiMon asks the hardware what actually exists and shows only sensors that answer with a plausible reading - nothing is invented to fill a gap.

An honest Neural Engine reading

The Neural Engine used to be shown as a percentage. macOS does not publish one, so that number was our own estimate and it has been removed: the reading is now power draw in watts, plainly labelled as activity rather than load. The metric is also off in the menu bar by default, since it sits at zero during ordinary work. On M5 and later, part of the AI workload runs on accelerators inside the GPU cores and will not raise this reading at all - Settings says so too.

Built-in stress test

A load generator with ready-made presets for processor, memory and graphics, plus a report of what the machine did while it ran. Useful for checking that a sensor really responds to load, for hearing when the fans come in, and for comparing one Mac against another. It can also be started from the terminal.

Settings organised by metric

Settings were rebuilt around the things being measured. Each metric - CPU, RAM, GPU, Neural Engine, battery, fans - now has its own section holding everything about it: menu bar visibility, graph colour, temperature. General keeps the settings that apply to the whole app.

Version numbers

The app now carries a proper version and build number and shows them in Settings, under General. This page arrived with them, so there is somewhere to look up what changed.

Version 1.0

9 August 2026

The first release. SiMon puts your Mac's vital signs in the menu bar and stays out of the way otherwise.

  • Processor, memory, graphics and Neural Engine activity, component temperatures and fan speed, each with a number and a small live graph.
  • A panel on click with recent history, per-core bars and memory detail.
  • Settings for which metrics appear, how often they are sampled, graph colours and width, light or dark appearance, and launching at login.
  • A diagnostic mode - SiMon --dump - that prints every reading once and exits, for reporting a suspicious value.
  • No network access of any kind, and no data collection. See the Privacy Policy.
