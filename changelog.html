What's New

SiMon - System Monitor

Every release of SiMon, newest first, described in plain terms. The version you are running is shown at the bottom of Settings, under General.

Version 1.3.1

14 August 2026

Housekeeping

Maintenance release. The application category is now declared explicitly, the copyright line was corrected, and the build no longer carries a quarantine flag from files used during packaging. Metrics, the panel, the history and the settings are unchanged.

Version 1.3.0

13 August 2026

The stress test moved into Settings

Checking that a Mac holds up under load is now a section of the Settings window, next to the metrics, instead of a separate window. The run keeps going if you close Settings, and reopening the section shows where it got to.

A word about safety

The stress test deliberately heats the machine, so it now says so plainly before it starts. macOS manages temperature itself and SiMon stops the run if a sensor passes 100 degrees, but you start it yourself and run it at your own risk.

Version 1.2.0

13 August 2026

History now survives a restart

Metrics are kept for a fixed stretch of time rather than a fixed number of samples, so the panel always shows the last ten minutes no matter how often SiMon polls. A day of history is also written to disk, which makes slow problems like a memory leak visible across restarts.

Only one copy runs at a time

Launching SiMon while it is already running now brings the existing copy forward instead of adding a second set of readings to the menu bar.

Honest scale for the Neural Engine graph

The graph used to be drawn against a fixed 8 W ceiling borrowed from the M1. It is now scaled to the highest power draw actually seen, and the caption tells you what that peak is. On this machine the real peak under a machine learning workload is closer to 2.8 W, so activity that used to look flat is now clearly visible.

Signing fixed

The notarisation ticket is now attached to the application itself, not only to the disk image, so macOS can verify SiMon without an internet connection.

This page

Release notes now have a home, and Settings has a "What's new" link that brings you here.

Apple Silicon only

SiMon requires a Mac with Apple Silicon. Intel Macs were never really supported - the Neural Engine, the temperature sensors and the split between efficiency and performance cores do not exist there - and the requirement is now stated plainly.

Version 1.1.0

13 August 2026

Processor load split into apps and system

The CPU reading now separates the work your own apps are doing from the work macOS is doing on their behalf. When the machine feels busy for no obvious reason, this shows at a glance whether an app or the system is behind it. The per-core bars also adapt their thickness to how many cores your Mac has, so they stay readable from an 8-core chip up to a 64-core one.

Memory and battery temperatures

Two more sensors joined the temperature readings, and you can now pick which of them appear in the menu bar. Sensor names differ between Apple chips, so SiMon asks the hardware what actually exists and shows only sensors that answer with a plausible reading - nothing is invented to fill a gap.

An honest Neural Engine reading

The Neural Engine used to be shown as a percentage. macOS does not publish one, so that number was our own estimate and it has been removed: the reading is now power draw in watts, plainly labelled as activity rather than load. The metric is also off in the menu bar by default, since it sits at zero during ordinary work. On M5 and later, part of the AI workload runs on accelerators inside the GPU cores and will not raise this reading at all - Settings says so too.

Built-in stress test

A load generator with ready-made presets for processor, memory and graphics, plus a report of what the machine did while it ran. Useful for checking that a sensor really responds to load, for hearing when the fans come in, and for comparing one Mac against another. It can also be started from the terminal.

Settings organised by metric

Settings were rebuilt around the things being measured. Each metric - CPU, RAM, GPU, Neural Engine, battery, fans - now has its own section holding everything about it: menu bar visibility, graph colour, temperature. General keeps the settings that apply to the whole app.

Version numbers

The app now carries a proper version and build number and shows them in Settings, under General. This page arrived with them, so there is somewhere to look up what changed.

Version 1.0

9 August 2026

The first release. SiMon puts your Mac's vital signs in the menu bar and stays out of the way otherwise.

  • Processor, memory, graphics and Neural Engine activity, component temperatures and fan speed, each with a number and a small live graph.
  • A panel on click with recent history, per-core bars and memory detail.
  • Settings for which metrics appear, how often they are sampled, graph colours and width, light or dark appearance, and launching at login.
  • A diagnostic mode - SiMon --dump - that prints every reading once and exits, for reporting a suspicious value.
  • No network access of any kind, and no data collection. See the Privacy Policy.
