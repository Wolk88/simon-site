This page describes the stress test found in the build distributed from this site. It is not part of the Mac App Store build.

The stress test and your Mac

SiMon can deliberately load the processor, the graphics and the memory to check that a machine holds up - useful when accepting a new Mac. This heats the machine and takes it over for the duration of the run.

This is safe under normal conditions. macOS manages temperature itself: it lowers clock speeds, spins the fans up and, in the extreme, shuts the machine down before anything is damaged. SiMon stops the run on its own if a sensor passes 100 degrees or the system reports a critical thermal state.

That said, you start the test yourself and you run it at your own risk. SiMon is provided as is, without any warranty. If a machine is already faulty, running it at full load may make the fault show - which is the point of the test, but worth knowing before you press Start.
