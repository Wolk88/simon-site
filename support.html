SiMon - System Monitor

SiMon shows what your Mac is doing, right in the menu bar: processor and memory load, graphics and Neural Engine activity, temperatures and fan speed. Click any metric for a panel with recent history and details.

Requirements

  • macOS 14 or later
  • A Mac with Apple Silicon (M1 or newer)

Common questions

The fans show "off". Is the app broken?

No. On MacBook Pro models the system stops the fans completely while the machine is cool, and the hardware reports both current and target speed as zero. SiMon writes "off" rather than "0" so the reading does not look like a failed sensor. Put the Mac under sustained load and the fans will spin up, with the real speed shown in place of "off".

Some temperatures are missing

Sensor names differ between Apple chips. SiMon asks the hardware which sensors exist and shows only those that answer with a plausible reading. If a sensor is not present on your Mac, its value is left out instead of being invented. On a Mac without fans the fan reading is absent for the same reason.

The Neural Engine always shows 0.0W

That is usually correct. The Neural Engine draws power only when an app runs a machine learning model. It stays at zero during ordinary work and rises when, for example, Photos analyses a library or an app performs image recognition.

The Neural Engine reading is watts, not a percentage - why?

macOS does not expose a utilization figure for the Neural Engine, only its power draw, so that is what SiMon shows. Treat it as an activity indicator, not a load percentage. It is most meaningful on M1 through M4 chips. On M5 and later, Apple moved part of the AI workload onto accelerators built into the GPU cores, so some machine learning activity will not raise this reading at all.

The menu bar block is too wide

Open Settings and turn off the metrics you do not need, each in its own section. You can also make the graphs narrower under General, down to 12 pixels.

How do I start the app automatically?

Settings, General, "Launch at login".

How do I remove the app?

Quit it from the panel and drag it to the Trash. It leaves nothing else behind apart from its preferences, which macOS removes with the app.

The stress test and your Mac

SiMon can deliberately load the processor, the graphics and the memory to check that a machine holds up - useful when accepting a new Mac. This heats the machine and takes it over for the duration of the run.

This is safe under normal conditions. macOS manages temperature itself: it lowers clock speeds, spins the fans up and, in the extreme, shuts the machine down before anything is damaged. SiMon stops the run on its own if a sensor passes 100 degrees or the system reports a critical thermal state.

That said, you start the test yourself and you run it at your own risk. SiMon is provided as is, without any warranty. If a machine is already faulty, running it at full load may make the fault show - which is the point of the test, but worth knowing before you press Start.

Reporting a problem

If a metric looks wrong, the most useful thing you can send is the output of the app's diagnostic mode. Open Terminal and run:

/Applications/SiMon.app/Contents/MacOS/SiMon --dump

It prints every reading once and exits. Include that output, your Mac model and your macOS version in your message.
